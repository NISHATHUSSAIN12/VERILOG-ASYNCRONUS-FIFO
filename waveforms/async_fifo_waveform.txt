================================================================================
KEY SIGNAL DEFINITIONS
================================================================================

wr_clk          : Write domain clock (10ns period = 100 MHz)
rd_clk          : Read domain clock (15ns period = 66.67 MHz)
wr_rst_n        : Write reset (active low) - released at 50ns
rd_rst_n        : Read reset (active low) - released at 100ns

wr_en           : Write enable - HIGH when data should be written
wr_data[7:0]    : Write data bus (8-bit values)
b_wr_addr[2:0]  : Binary write address (0-7)
g_wr_ptr[3:0]   : Gray-coded write pointer (includes extra bit for full detection)
full            : Write FULL flag - prevents overflow

rd_en           : Read enable - HIGH when data should be read
rd_data[7:0]    : Read data bus (8-bit values)
b_rd_addr[2:0]  : Binary read address (0-7)
g_rd_ptr[3:0]   : Gray-coded read pointer (includes extra bit)
empty           : Read EMPTY flag - prevents underflow

syn_g_wr_ptr    : Synchronized write pointer (in read clock domain)
syn_g_rd_ptr    : Synchronized read pointer (in write clock domain)
XX              : Metastable state (transitioning in synchronizer stage)


================================================================================
IMPORTANT OBSERVATIONS
================================================================================

1. CLOCK DOMAIN INDEPENDENCE
   └─ Write clock (100 MHz) and Read clock (66.67 MHz) operate independently
   └─ No timing relationship between domains required
   └─ Different frequencies stress-test the CDC design

2. POINTER SYNCHRONIZATION
   └─ Write pointer: 0x04 reaches synchronized stage after 3 read clock cycles
   └─ Read pointer: 0x05 reaches synchronized stage after 3 write clock cycles
   └─ Gray-coded format prevents multi-bit metastability

3. EMPTY/FULL FLAG TIMING
   └─ empty flag: Asserts ~150ns after last read (3 rd_clk cycles)
   └─ full flag: Would assert after 8 writes (FIFO capacity reached)

4. DATA INTEGRITY
   └─ Read data (00-07) exactly matches written data
   └─ First-In-First-Out ordering maintained
   └─ No data corruption across domains

5. SYNCHRONIZATION DELAY IMPACT
   └─ Flag updates lag pointer updates by 2-3 cycles
   └─ Must account for this latency in system design
   └─ Software should not assume instantaneous flag response


================================================================================
GRAY CODE EXAMPLES (ADDR_SIZE=3 means 4-bit pointers)
================================================================================

Address Transitions:
  0 (0000) → 1 (0001)  |  Gray: 0000 → 0001  ✓ One bit changes
  1 (0001) → 2 (0010)  |  Gray: 0001 → 0011  ✓ One bit changes
  2 (0010) → 3 (0011)  |  Gray: 0011 → 0010  ✓ One bit changes
  3 (0011) → 4 (0100)  |  Gray: 0010 → 0110  ✓ One bit changes
  4 (0100) → 5 (0101)  |  Gray: 0110 → 0111  ✓ One bit changes
  5 (0101) → 6 (0110)  |  Gray: 0111 → 0101  ✓ One bit changes
  6 (0110) → 7 (0111)  |  Gray: 0101 → 0100  ✓ One bit changes
  7 (0111) → 0 (1000)  |  Gray: 0100 → 1100  ✓ One bit changes (wrap around)

Advantage: If metastability occurs, only one bit can be wrong, not multiple!
